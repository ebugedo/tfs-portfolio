# LinkedIn Post: Tfs.Portfolio API

Beyond a prototype…

REST API built with OpenCode + OpenSpec (SDD) + free cloud models.

Going from a Proof of Concept (PoC) to a production-ready API requires strict contracts, solid architecture, and enterprise standards. In this project we applied Spec-Driven Development (SDD) with OpenSpec using OpenCode as the primary development tool, supported by free cloud models.

💡 The result: A functional API deployed in production without writing a single line of code by hand, guiding the entire software engineering flow through precise specifications and AI agents.

📄 Attached to this post: Tfs.Portfolio documentation: REST API with .NET 10, ASP.NET Core and Entity Framework Core 9, following Clean Architecture and DDD with OpenCode and OpenSpec. Includes C4 documentation, API endpoints with X-API-Key, deployment on VPS with Docker and Nginx, and CI/CD with GitHub Actions to GHCR.
