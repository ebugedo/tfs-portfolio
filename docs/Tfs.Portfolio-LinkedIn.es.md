# LinkedIn Post: Tfs.Portfolio API

Más allá de un prototipo…

API REST construida con OpenCode + OpenSpec (SDD) + modelos gratuitos en la nube.

Pasar de una Prueba de Concepto (PoC) a una API lista para producción requiere contratos estrictos, arquitectura sólida y estándares empresariales. En este proyecto hemos aplicado Spec-Driven Development (SDD) con OpenSpec utilizando OpenCode como herramienta principal de desarrollo, apoyándonos en modelos gratuitos en la nube.

💡 El resultado: Una API funcional y desplegada en producción sin haber escrito ni una sola línea de código a mano, guiando todo el flujo de ingeniería de software a través de especificaciones precisas y agentes de IA.

📄 Adjunto en este post: Documentación de Tfs.Portfolio: API REST con .NET 10, ASP.NET Core y EF Core 9, siguiendo Clean Architecture y DDD con OpenCode y OpenSpec. Incluye documentación C4, endpoints API con X-API-Key, despliegue en VPS con Docker y Nginx, y CI/CD con GitHub Actions a GHCR.
