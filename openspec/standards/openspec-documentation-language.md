# OpenSpec Documentation Language

## Rule

All OpenSpec change artifacts MUST be written in **English**.

## Scope

This applies to every document generated under `openspec/changes/<change>/`, including but not limited to:

- `proposal.md`
- `design.md`
- `tasks.md`
- Any delta spec under `specs/` referenced by an OpenSpec change

## Requirement

- Proposals, designs, task lists, and specs MUST use English for all prose, headings, and capability descriptions.
- Code identifiers referenced in these documents remain in English per `coding-standards.md`.
- Spanish is not permitted in OpenSpec artifacts.
