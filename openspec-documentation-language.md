# OpenSpec Documentation Language

## Standard

All documents generated by OpenSpec related to SDD (Spec-Driven Development) must be written in **English**.

This applies to all OpenSpec planning artifacts, including:
- `proposal.md`
- `specs/<capability-path>/spec.md`
- `design.md`
- `tasks.md`

## Scope

This standard covers documentation produced through the OpenSpec workflow (`openspec new change`, `openspec apply`, etc.). It does not retroactively require translating existing project documentation.

## Rationale

English is used as the common language for architecture and engineering documentation in this project, ensuring consistency across OpenSpec-generated artifacts and alignment with the broader technical documentation.
